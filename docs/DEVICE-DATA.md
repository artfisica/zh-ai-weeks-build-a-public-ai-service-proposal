# Device data and recovery

The page now explains, before generation, that the sentence and map context go to the connected provider. “Save on this device” can be switched off before entering a situation. Turning it off removes the saved map, answers, conversation and undo history from this browser and keeps subsequent work in memory for the tab. Turning it on saves the accepted situation again. Browser language and the save preference remain; rehearsal tokens are memory-only. This switch does not delete provider-side records or an exported/copied plan.

Storage failures are visible. A full/blocked browser store leaves the current map usable in memory and recommends printing before closing. Malformed saved maps are rejected before state is installed; Start over clears them. Map caches remain in memory instead of duplicating up to twenty maps in persistent storage. The accepted map and five undo snapshots are still saved when enabled.

This is a shared-device control, not encryption or a confidential-data platform. Browser profiles and scripts running on the same site can access local storage. Avoid identifying permit numbers, addresses and health details in the public prototype. The operator must establish the provider retention account and publish its own contact before a resident pilot. No processing-location or retention guarantee is inferred from the model name.

A real-browser walkthrough should cover an initial generation, Keep/Adopt/Undo, Explore, a failed request, reload, disabling storage, clearing data and Print/PDF. Keyboard labels have been added to the start and free-response fields. Automated regressions do not replace sessions with residents or assistive-technology users.

Scenario and completion identities use the complete relevant inputs instead of a short hash. Legacy completion marks are migrated against the saved map, including Undo snapshots. The accepted situation and answers remain available; old alternative-answer caches without an exact context are not reused. Saving disabled in one tab is also honoured by other tabs on the next save and through browser storage events.
