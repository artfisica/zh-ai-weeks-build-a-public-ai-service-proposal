## Language to use precisely

- “These are **proposed** paths generated by Apertus. The URL is chosen from a fixed catalogue. The catalogue note and the match between note and step await review.”
- “No commune has reviewed or endorsed this. A municipal content owner would need to approve a narrow claim before it becomes a rule in a service.”
- “The proxy sends the prompt to the configured Swisscom service. We have not independently established a processing-location guarantee from the API response.”
- “The transport data is linked as a possible future integration. The prototype does not calculate a route or a fare.”
- “I want to test whether this can become a reviewed, maintainable local service. The interaction is working; the civic content and operations are the pilot work.”
